# 設計制約（変更禁止ルール）

このファイルはBTC自動売買シミュレーターの「意図的な仕様」を記録するものです。
自動最適化（optimizer.py）はここに記載された内容を絶対に変更してはいけません。

---

## [CONSTRAINT-001] grid_last_price は売買時のみ更新する

**対象コード**: `strategy_grid()` の待機時（elseブロック）
**禁止**: 待機時に `state["grid_last_price"] = price` と書くこと
**理由**: 待機時に更新すると小刻みな価格変動でグリッドがリセットされ、グリッドトレードが機能しなくなる
**正しい動作**: 前回の約定価格から50万円以上動いた時だけシグナルが発生する
**修正履歴**: 2026年5月24日に初期実装のバグとして発見・修正済み

---

## [CONSTRAINT-002] combined_last_price は売買時のみ更新する

**対象コード**: `strategy_combined()` の待機時（elseブロック）
**禁止**: 待機時に `state["combined_last_price"] = price` と書くこと
**理由**: CONSTRAINT-001と同じ。複合戦略のグリッド部分も同一の設計原則に従う
**修正履歴**: 2026年5月25日に自動最適化によるリグレッションとして発見・修正済み

---

## 新しい制約の追加方法

新たに「変えてはいけない仕様」が見つかった場合は、以下の形式でこのファイルに追記してください：

```
## [CONSTRAINT-XXX] タイトル

**対象コード**: 関数名・行番号など
**禁止**: 具体的に何をしてはいけないか
**理由**: なぜその仕様が必要か
**修正履歴**: いつ・どのような経緯で確定した仕様か
```
